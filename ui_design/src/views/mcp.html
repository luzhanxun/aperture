MCP Server 把素材库变成 AI 可调用的工具集：检索、读元数据、统计上传、导出 Excel。

可用工具

工具 作用 状态
search_assets 按关键词、分类、时间与可见范围检索素材 可用
get_asset_metadata 读取单件素材的完整元数据与授权状态 可用
aggregate_uploads 按上传者、分类与时间统计上传量 可用
export_to_excel 将检索或统计结果导出为 Excel 可用

工具只读为主，唯一写操作是导出文件；任何调用都记入审计日志。

Agent Skill

WorkBuddy 首个接入

技能包封装三个动作，让智能体按中心规范选材与交付。

选材 授权确认 导出交付
  • 选材时优先返回可商用素材，并标注授权范围。
  • 导出前必须展示素材清单与用途，由使用者确认。
  • 不得绕过素材库直接分发原片下载地址。

边界与约定

  • 智能体只读素材与元数据，不修改元数据、不删除素材。
  • 导出的 Excel 不含原片地址，仅含素材编号与预览链接。
  • 预览链接仍受有效期与访问上限约束。
  • 每次工具调用记录账号、参数、结果与耗时。

一期是否开放导出原片、是否允许外部账号接入 MCP，需要与中心确认。
